PocketTrainer

Learn AI on the phone you already have — even an old one. No server, no laptop, no internet. Congressional App Challenge 2026 · Luckison Du

Try it in 60 seconds

  1. Open the web version (no install): Run the 30-second demo
  2. It runs the same training twice with the same interruption — once without protection, once with — by itself (about 30 seconds).
  3. Compare the two results:
Protection off → accuracy ≈ 10%
training silently ruined, no error shown
Protection on → accuracy ≈ 87%
error detected and repaired automatically

On the web and Android versions the interruption is a software simulation (labelled in the app). On iPhone 16 the same effect was reproduced with a real GPU recovery event. Numbers are from our own test logs.

What is inside

  • Train a small AI on-device (5,000 training photos, 2,000 unseen test photos, 10 classes) — about 87% accuracy.
  • Self-check every step, atomic checkpoints, resume after a crash (identical result).
  • Export the trained model to Core ML and PyTorch-readable weights (iPhone).
  • Search GitHub and Hugging Face, notes, assistant, 5 languages, works offline.

Languages and tools: Swift/SwiftUI (iPhone), Kotlin/Jetpack Compose (Android), HTML/CSS/JavaScript + WebAssembly (web). AI tools (Claude) were used and are disclosed file by file in the repositories' AI_DISCLOSURE.md.
